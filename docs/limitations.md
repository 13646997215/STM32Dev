# 规则口径与能力边界

## 目前可以交付的范围

全部任务所需的软件组件与七个分支已进入同一构建目标；分支的数值、解析、计时和状态转换可用PC上的真实C代码测试。软件允许在开始一次自主运行前选 profile，运行中禁止参数和手动接管，PC失联不取消 AUTO。STOP 和本地按键始终可终止测试，终止的那次不应冒充自主测评完成。

## 必须保留的规则问题

1. 任务2资料写“位置不限”，最终表又允许学生选位置。软件只使用已声明的起始坐标，没有外部定位器件，不能识别任意未知横向偏移。`start_x/y` 是设置条件，不是测量结果。
2. 任务5要求完成平衡与返A，任务6却要求“完成5之后，在平衡状态下加第二块”。当前提供 WEIGHT_RETURN 与 REWEIGHT 两个开始前选定分支；后者先平衡保持、检测扰动后重新平衡。**没有虚构一个能同时满足两种互相冲突起点的自动串联流程。**
3. 测评1→6顺序与“中途不能下载”已由单固件覆盖；每项之间是否允许重新摆放、重新选择开始模式，仍须老师确认。当前没有宣称已实现无需任何场地初始化的1→6连续运行。
4. 平衡90s计时起点不一致；当前从 START 起算，取保守口径。任务4从稳定10s达成后起算60s；预测评分支从找倾覆事件起算5s。规则若改变，应先改测试再改状态机。
5. 任务7场地尺寸/指定轮现场确定，同时不能现场改设置，合法初始化方式须确认。当前参数化提供能力，不能把赛前写参数当然视为规则允许。

## 可观测性

单路FG只能计数，无法独立区分正转、反转、外力推动和回滚。固件在已驱动后保留最后指令方向假设用于停转滑行；换向须PWM=0、静默等待和低反馈后再改方向。`pose_valid=1` 仅表示未触发内部一致性故障，**不表示位置经过外部测量或独立验证方向**。打滑、回滚、磁干扰不会必然被识别。

GY953给姿态，不给绝对平面位置。即使校准PPR/轮径/航向，0.5×0.3m两圈、40mm指定轮圈与压线仍受累计误差影响。内部8mm容差只是估计坐标上的控制阈值，不是实际精度证据。路径以车体参考中心的矩形为基础，指定轮偏移用于最终停靠检查；现场边线如何对应车体/指定轮路径，须按实际场地冻结轨迹与包络，不能直接认定无压线。

板长1.6m、端高差严格小于30mm，对应倾角约 `asin(0.03/1.6)=1.074°`。课程GY953手册标称测量/重复精度2°，虽然支持输出0.01°缩放，分辨率/精度并不相等。零偏标定后是否足够，必须以真实端高差对照。软件连续10s计时不能代替高度测量。

## 机械与控制待测

轮径67mm来自用户，轮距140mm、长200mm、宽190mm、PPR738均为占位。外廓检查只覆盖声明的中心对称矩形和静态当前姿态，不是已验证的制动距离/边缘测距。坡面姿态、悬空、地面摩擦、支撑点/重心、供电下陷、磁干扰与电机死区均需现场数据。35%断续、40%能转是基础台架观察，不是闭环已整定。

软件可以列出已知风险、给出故障处理和测试入口，无法保证避免所有未测物理问题。当前无需新增传感器即可先联调；不能以不存在的传感器补全精度结论。
