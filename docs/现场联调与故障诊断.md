# 任务 1–6：现场联调与故障诊断

> **软异常版本更新：**自主流程单次 FG 异常过滤并告警，不再因此锁存 FEEDBACK；流程超时及统一流程返回边界改为告警，不证明达标。IMU 过期、无效或倾角超限时输出为零等待恢复；换向互锁保留。原文中有关这些条件会锁存故障的说明属于旧版本。FG 异常后的位姿已不可信，不能把估计坐标当作完成证据。

2026-10-30 本机软件验证：15 组真实 C 测试、23194 项断言，41 项 Python 测试，离线 GUI smoke 以及 Debug/Release 构建和产物检查均通过。具体记录见本工程 `test-results/verification.json`；未连接或操作硬件。

## 当前软件与实际成绩

源码实现了对准、上板、平衡、返回等状态及独立的重加重 profile。**编译、测试、上位机诊断和估计轨迹不能证明实车成功，也不能证明板端高差满足要求。** 任务 5 要求平衡后返回，而任务 6 文字又要求在平衡状态加第二个配重；它们的现场衔接和能否在任务之间重新摆放应向老师确认。

PA0 默认启动 `PROFILE_BALANCE_RETURN`，首次达到平衡条件后返回，不等待第二次配重，不能宣称自动完成任务 6。`PROFILE_REWEIGHT` 首次平衡后等待扰动，检测扰动并再次稳定后返回，但目前需要在运行前选择该 profile；这个分支是否符合现场测评规则，以及扰动信号能否可靠识别，必须实测。不要在正式自主运行过程中操作上位机作为代替，题目禁止人为干预、中途重新下载。

题目中平衡定义是端点高差严格小于 30 mm，保持 5 秒以上，任务 3 还要求保持 10 秒；板长 1.6 m，对应角度约 1.07°。上位机的 ±1° 统计只是来自 IMU 的估计，输出分辨率不是测量精度；应以端点实测高度和现场计时复核。单路 FG 没有独立方向测量，轨迹和里程不是外部定位；打滑、滚动与地磁干扰可以造成偏差。

## 测试前

1. 完成软件编译后，使用本工程的 Debug ELF。电机 12 V 在下载、复位、暂停前断开；此前保持 RESET 时电机会转。重新运行且确认输出为零后，按实际条件连接电机电源。需要实车测试时由现场操作者执行，车体架空或有防跌落保护并准备手动切断 12 V。
2. 使用包根 `03-Open-Monitor.cmd` 打开上位机，选择 PC 端 HC-05 对应 COM，连接 115200/8N1。确认 IMU 数据持续变化、年龄正常、状态和故障码有更新。通信丢失时 PC 不能确认车辆状态，AUTO 也可能继续运行，不能把关窗口当作停车。
3. 首先观察左右 FG 和 PWM：无控制目标与停车时 FG 应接近零，低速架空时两轮的频率随运动变化。采集原始记录，按现象核对 PB8/PB9、共地、走线与供电；不要凭一次频率异常就认定具体元件损坏或直接加任意电容。
4. 自动模式 FG 异常检测使用配置的 `max_rpm`、PPR、实际周期与余量；超限时丢弃该区间位置脉冲并告警，不因此立即结束任务。真实快速运动也可能触发；低于阈值的干扰不一定检出。当前实测参数 `fg_fault_en=0` 会关闭 FG 丢失故障，不能把零频率视为健康证明。

## 一轮完整观察

建议录屏并保留上位机本轮 CSV：记录从启动、ALIGN 对准、CLIMB 上板、BALANCE 平衡、RETURN 返回到 ARRIVED 或 FAULT。观察航向、Pitch、左右 FG/PWM、状态与异常提示；出错先记录并安全停车，再根据下表检查，不要同时调整多项参数。状态变化或 CSV 分析只说明设备上报的情况，现场仍需观察车轮、板、位置和高度。

| 现象 | 可能情况与处理 |
|---|---|
| `FEEDBACK(3)` 或某轮 FG 峰值远超正常 | 保留日志，断动力后检查该轮反馈接线、供电、信号和噪声；比较轮子实转与频率，确认配置中的 PPR/最高转速是否适用。不要用另一轮脉冲冒充该轮位置。 |
| PWM 有输出而 FG 很低 | 可能未起转、机械卡滞、反馈断线或采样异常；先看实际轮子，再查电源、负载和线。不要只根据 GUI 推断原因。 |
| `IMU(2)`、年龄持续增长 | 检查 IMU 电源、PA9/PA10 连接及数据；记录故障前样本。界面最后数字可能过时。 |
| 超时或返回距离告警 | 查看当前阶段、坐标质量和运动；自动流程继续不等于已到 A 或按时完成。 |
| 平衡来回摆、进带时间短 | 对照每轮报告及实测板高度，检查是否触及限位、打滑、死区和 FG 质量。积分过零清理已加软件回归，增益、死区或实际稳定性仍需现场整定。 |
| 对准反复摆动或绕远 | 确认车体方向、IMU 安装及磁场干扰；方向与角度应通过现场观测确认，不能只靠地图估计。 |
| `TILT(7)` | 把车置于允许姿态，检查当前配置的倾角上限及零位；物理原因排除后再清故障。 |
| 蓝牙断线、遥测过期 | 保持现场安全，按现场停止方案处置；重连后确认真实状态，旧界面读数不代表当前状态。不要假定 AUTO 已因关窗口停下。 |

课程规则边界、场地尺寸与任务说明以 `docs/planning/evidence/04-机器人跷跷板题目说明.txt` 和原 PDF 为准。上位机建议是基于遥测的规则提示，不能识别所有可能的硬件、机械和地磁问题。
