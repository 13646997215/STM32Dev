# 软件验证记录（2026-10-17）

本记录对应当前预备交付；只运行PC软件与ARM交叉构建。没有打开COM、探针连接、下载、复位或电机动作。

## 已验证

- 11组实际C测试通过，合计13224条CHECK/NEAR断言；其中包含数值循环，不能等同为13224个独立实物工况。
- 9项Python/真实C编解码互通测试通过。
- Tk上位机在离线演示模式启动、运行事件循环并关闭成功；未逐项执行真实串口GUI操作。
- Debug/Release交叉构建通过；当前构建日志无编译/链接警告。
- ELF内存、入口区、核心函数收录与强IRQ定义通过；Flash LOAD不再具有RWX属性。
- 基础工程123个文件hash不变，Drivers/Middlewares与基线完全一致，Core用户区以外未改。
- App/BSP/PC源码扫描未发现eval/exec、shell=True或所列私钥/凭据特征。该特征扫描不等于所有安全问题已排除。

链接器Flash区域实际含对齐填充，以build log与BIN长度为准。FreeRTOS的15KB heap已在bss，CourseTask的3KB栈从该heap分配，不重复加到RAM统计。运行高水位/最坏耗时还没有实测。

完整命令、退出码、输出、源文件与产物hash见 `test-results/verification.json`；初始stub失败和修复前回归记录见各 `*-red` 文件。当前红日志为历史证据，不代表最终版本仍失败。
