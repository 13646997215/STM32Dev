# 任务1台架：按Pitch正负调平到零

2026-10-19本轮目标以用户指令为准：Pitch正→前进，Pitch负→后退，接近零→停；Yaw不参与左右轮控制。电机1=左轮（PB6/PB8/PB4），电机2=右轮（PB7/PB9/PB5）。当前未装机，使用真实IMU手动倾斜、真实双轮架空验证联动，不能据此判定真实跷跷板已经平衡。

## 根因与课程口径

旧版台架有“相对启动倾角变化3°持续200ms后DONE”的结束条件，水平时则一直前进并根据Yaw差速。这与本轮要求不符，现已移除。日志中ACK FAULT/fault=7对应另一条独立保护：绝对Pitch超过max_tilt_deg（默认18°）会停车并锁存。仅凭日志没有触发时角度，不能断言具体抬高到了多少度。故障后按启动不会解除保护；需回到允许姿态、清除故障，再重新启动。

原任务书第1项字面是“到C附近，以跷跷板失衡为准”，10s平衡保持属于第3项。本轮按用户明确的新目标实现任务1 Pitch调平，原PDF及证据文件不改；任务2–7原分支保留。正式任务1说明见[实际任务流程](task1-practical-run.md)。

GY953是九轴融合模块；磁场分量会随姿态变，但理想的倾斜补偿应校正这种变化，纯俯仰并不必然意味着真实航向改变。观察到Yaw联动也可能来自磁干扰、标定或融合误差，仅凭现有日志不能归因某一个。依据[NXP倾斜补偿指南AN4248](https://www.nxp.com/docs/en/application-note/AN4248.pdf)，本轮直接将Yaw移出纵向调平控制输入，保留原始显示，不改造传感器内部融合算法。

## 控制行为与边界

- 零位始终是参数key30，当前0°；不是每次点击时的姿态。换算为pitch_sign×(所选Euler轴−pitch_zero_deg)，轴key101=1、符号key33=+1。
- 共用Task1_Update调平器：正负号严格对应前后，不让微分项或积分残留反转方向。误差越大，目标越大，速度上限取key20的max_v（2026-10-20起不再固定0.04m/s）。该速度仅供正式标定后的轮速闭环；台架不声称实际速度。
- 默认|Pitch|≤0.5°立即PWM0，保持HOLD；从停止再次启动需|Pitch|>1°，用滞回避免零位抖动。移动过程中0.5°–1°之间仍可继续接近零位。HOLD不是故障，不解除ARM，再倾斜会继续运动，无需反复点击。
- 台架运动时两路给出相同40–45%占空比，克服此前实测低占空比起动困难；这是受限开环输出，不能保证两个真实轮速相等。Yaw仅显示，不产生差速；电气前进映射仍由key102/103决定。
- 正反换向先让两轮PWM0，使用现有Motor_Update换向保护：默认至少200ms、FG静默且速度估计足够低后切方向，再启动；任一路仍在等待，双轮都不加电。若一直不静默，2.5s后MOTOR故障。FG只提供脉冲，不能独立测方向。
- 每次台架最长60s；GUI每100ms发送绑定本次启动序号的续命，超过500ms未收到则TIMEOUT停车。关闭/断开/ACK超时停止续发；重连、清故障均不自动重启。
- 保留18°倾角保护（key41）、IMU默认200ms时效、调度延迟保护、UART错误与本地停止。只在实际请求连续运动超过1.5s后检查FG缺失/过期；正常零位停车和换向静默不当成FG故障。
- mode4/pose_valid=0，不把架空FG积分为地面坐标；不改cal_flags，不绕过普通ARM/START标定门槛。启动还要求无故障、未ARM/mode0、有效配置、max_duty≥0.45、IMU有效且两轮已停止。
- 新启动magic是T1LV（54 31 4C 56），旧T1BN拒绝，防止旧GUI用旧目标启动新控制。固件与GUI必须同步更新。

## 一轮操作（VS Code与上位机按钮）

1. 先断电机12V，双轮架空固定，保留独立12V切断通路。FG黄线回PB8/PB9，IMU及蓝牙沿用已通过的接线。
2. 从包根`02-Open-VSCode.cmd`打开`projects/F401_COURSE`，点击“生成”，选择STM32Cube: Course ST-Link后启动调试下载；停在main后点“继续”。下载、复位及暂停期间电机12V都保持断开。已知保持RST电机会转，本次软件不能解决该硬件时段。
3. 关闭旧上位机，重新打开PC/启动上位机.cmd并连接蓝牙COM。在“参数与标定→加载并逐项发送”选择PC/config.task1-bench.json，等待11项ACK OK。它只设轴/符号、零位、增益/容差、输出上限与18°保护，最后保持flags00；参数只在RAM，复位需重载。仍有故障时放平IMU后点“清除故障”。
4. 确认固件持续运行、ARM0/PWM0，再接电机12V。点击一次“启动任务1台架（双轮架空）”，不用点普通ARM或“启动选定任务”。水平时不转是新目标的正确行为。
5. 在同一轮60s内连续观察：前端抬高约+5°→左右轮对应前进；缓慢回到0°→双轮停；前端压低约−5°→等待停稳后双轮对应后退；再回0°→停。保持Pitch不变，仅水平转Yaw，PWM目标应不变。手动俯仰限制在±5–10°，不要越过18°保护。
6. 看状态：HOLD/PWM0/ARM1表示近零等待；BALANCE表示调平；TILT(7)是倾角保护；TIMEOUT(6)是60s会话到期或500ms续命断流；FEEDBACK(3)检查实际电机和黄线；MOTOR(8)检查是否一直滑行/FG异常。故障不自动清除，不连续按启动碰运气。
7. 结束点STOP，先断电机12V，再停止调试或断控制板电源。若物理方向不符，STOP后按实际车体前后核对key102/103，不通过反接12V解决。

原始数据记录、CSV与VS Code实时监视仍可用：g_course.pitch、g_course.mission.v/w、g_course.motor[0/1].direction、g_course.pwm[0/1]、g_course.fault。遥测PWM是绝对占空比，方向看实物或上述direction变量。故障日志的Pitch是收到遥测时的值，未声称精确捕获触发瞬间。

装机后仍需标定安装零位、轮速/里程与实际控制响应；40%最小台架输出及默认增益不能证明实车不振荡。GY953手册的精度指标不能被软件0.5°容差替代，课程端高差<30mm仍需独立量测。
