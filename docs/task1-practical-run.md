# 任务1：按本轮目标从A端纵向调平

原任务书第1项为从A端出发，60秒内运动到中心C附近，以跷跷板失衡为判据。本轮用户明确要求改为Pitch正前进、负后退、零位停，现PROFILE_A按此实现。该口径与原第1项字面不同；第3项的10秒保持不混为本轮台架验收。原文与证据保留。

未装机、手动摇摆真实IMU并观察架空双轮时，使用独立的[任务1台架](task1-bench.md)入口；该模式已准备，与本页正式地面试跑及标定准入分别标识。

## 已有软件

App_Command接到正式任务1启动后，将声明的A端起点设为x=0/y=0，Mission_Start进入BALANCE。起点是摆放约定。任务1按已摆正的跷跷板轴线进行纵向里程估计，不用磁航向投影里程；这是假设车不横移/不偏转，不能证明真实横向位置或防掉边。

正式任务与台架共用Task1_Update：以配置零位为目标的正负反馈、0.5°停车与1°重新运动滞回、速度上限取key20的max_v（2026-10-20起不再固定0.04m/s；此前该硬上限使倾角超过约1.6°后指令速度恒定，实测表现为"倾角变大速度没变化"）；正式任务输出由已标定的轮速PI执行，w始终0，不读取Yaw产生差速。零位立即停轮，并且|Pitch|≤0.5°、角速度≤1°/s连续1s后DONE/解除ARM/LED亮；这1s仅用于本轮任务1结束确认，第3项仍是10s。正式任务最大60s，IMU、默认18°倾角、里程/外廓边界与故障保护保留。台架HOLD不结束，可继续手动摆动到会话60s结束。

正式任务1还保留key44（seek_max_m，暂定1.25m）的前进里程上限；后退不超过声明A起点之后0.05m。二者是有界软件走廊，需根据装车起点/车体外廓与实物调整，不能代替真实边缘感知。台架不使用这些虚构地面位移。

## 第一轮实践集中观察

装机后完成轮速与零位标定，再从A端按板轴线摆正，集中观察前进是否使正Pitch减小、过零后是否需反向、能否在容差内停车确认及耗时。用JSONL/CSV记录一整段过程。若出现振荡或冲过平衡点，依据实际惯性、FG、Pitch延迟整定增益/速度，不能把架空手摇通过称为闭环整车通过。用户手动倾斜输入不受轮子反作用影响，无法测试实车稳定性。

参数集中配置：安装X前/Y右/Z下，Pitch前抬增大；pitch_axis/sign/yaw_sign按预定方向。pitch_zero_deg和board_heading_rad当前0为占位。Task1的倾角环为PID：key34比例、key35积分、key36微分，另有key38停车容差、key39稳定角速度、key41倾角限值、key20速度上限；不使用key37平衡反号或key42/43倾覆触发，后者保留给其他任务。微分项限幅为比例项的一半、积分进入容差即清零，避免快速回位时指令被清零或积分饱和。轮距、外廓、PPR、速度PI仍需实测；等占空比不等于等轮速。

该文档是整体试跑路线，不是现在启用运动的操作指令。车架尚未安装、复位保持期间电机自行转的问题仍未解决，当前flags0。启动任务1实际需要对应已完成实测的CAL_PATH有效位及ARM；不得为了进入流程把未完成的标定写成通过。软件与参数准备可继续，实物能力根据装机后整段过程判断。
