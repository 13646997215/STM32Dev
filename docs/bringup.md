# 后续硬件联调与标定清单

此清单供用户集中接线后执行，本次没有执行其中硬件动作。先保持轮子离地和独立电机断电通路，使用VS Code按钮和上位机，不需要重新转换旧工程。

## 1. 不驱动电机的串口与IMU

- 核对接线契约，断电完成接线。最初选CH340接USART2，暂不接第二个UART发送器。
- 电机12V保持断开，后续自行下载Debug固件，在main继续运行；应看到mode0、ARM0、flags0、PWM0。检查本地按键停止行为，蓝线安全缺省要另行验证。
- 上位机选择明确的COM端口→连接。确认ACK和20Hz遥测，Euler年龄持续小于200ms、正反倾斜三轴符合厂家上位机，IMU good增长、bad不持续增长。
- 摆正机器人沿板+x方向，记录IMU安装pitch轴、pitch零偏、yaw_sign、pitch_sign及board_heading。不要将任意启动朝向自动当板方向。GY953磁校准会写模块内部状态，本软件不自动执行。
- 看 `g_runtime_max_us`、`g_control_stack_free_words`、`g_free_heap_bytes`；记录最坏串口负载与FG情况下数据，不能凭空把软件设定10ms写成实测周期达标。

## 2. 方向与FG比例

- 先验证电机上电/MCU复位/MCU掉电/调试暂停的停止通路。蓝线悬空会转，软件CCR=0不覆盖MCU尚未执行时段。实物确认后再记录CAL_POWER。
- 轮子离地，一次一台；按已通过的基础测试确认车体前进对应PB4/PB5的电平，填key102/103。不要直接沿用“电机轴正转=车体前进”。
- 在固定方向手动转/低速驱动输出轮若干整圈，记FG接受上升沿变化：`PPR=ΔN/轮圈数`。左右分别测，多次检查漏脉冲和接触抖动；不把738直接当实测。
- 确认FG Hz与PWM/转速趋势、停止后Hz过期归零。FG没有方向，反向时不能拿计数单独证明方向。

## 3. 轮速PI与最小动作

- 解除ARM后先写全部参数，普通参数修改会清空标定标志。只有实测完成后才在key100设置对应位。ARM仅需36，但MANUAL_SPEED需54；DUTY仍受max_duty限制和换向等待。
- 从已知可启动区间验证低占空比，上次35%断续、40%稳定只作起点。测两轮、两方向、空载/装车的启动和维持阈值，确认前馈/deadband。当前各方向共用每轮deadband，若方向差异明显应扩展参数和测试后冻结。
- GUI“轮速RPM”输入左右目标；记录目标/FG/PWM响应，先调kp再ki，验证饱和退出、低速、反向静默和反馈断线。按键或STOP结束，断电后再改线。
- 目标0是真0；非零最小步长是否超过死区需实测，不能用上位机曲线看起来平滑替代实际轮子运动。

## 4. 几何、航向与里程

- 用户确定车架后填写轮距、包络长宽、指定轮偏移。轮径67mm需考虑受载有效轮径。底层距离：`s=ΔN/PPR × π×D×wheel_scale`，一个校正量只补偿一次。
- 测已知直线距离L，与估计距离E比较：`new_scale=old_scale×L/E`。左右/正反分别记录，不把轮胎打滑混进PPR定义。
- 固定合法起点/朝向后测试角度wrap、原地转向、直行与倒车，检查坡面是否回滚。估计pose_valid和方向假设位不是真实定位精度指标。
- 实测停止距离，按实际速度和外廓设置留边；当前没有边缘传感器和经验证的预测制动边界。先验证最窄/最差姿态下整车包络再上板。

## 5. 上板、平衡与配重

- 确认老师允许的起始位置集合和任务计时，填start_x/y、climb_end、seek最小/最大距离、tip_delta。先测试入口姿态，再测试找倾覆，记录200ms事件去抖是否识别真正失衡而不是坡面颠簸。
- 用独立真实端高差对照传感器倾角，标定零偏及balance_sign。正负小扰动下输出必须减小端高差；错误符号会使板加速倾覆。
- 从受限输出调平衡kp/kd，再小量ki；观察滤波速度与滞后。稳定必须新姿态帧连续满足倾角和变化率10s，扰动后重新计时。阈值不满足真实30mm时不得靠放宽软件阈值“过测试”。
- profile3无配重平衡后返A；profile4一配重相同流程；profile5先平衡后持续保持，加入第二块后的姿态扰动触发再调节。软件检测的是扰动，不是砝码个数/质量。
- 固定参数后做20–50%质量、可达位置组合；记录真实时限、LED、端高差、回A停位与全车投影。任务5/6现场衔接确认前不宣称全赛程达标。

## 6. 附加与正式冻结

- profile7两圈独立测评；填现场合法尺寸与指定轮偏移，验证实际压线及40mm圈，分别记录模型估计误差和真实位置误差。
- 不加地面/板面引导物。参数和模式在运行前冻结，AUTO运行中不允许远程接管/修改；使用一次固件，不在测评中下载。
- 形成每次运行原始JSONL、CSV、视频/标尺、版本/hash、配置、起点和终点记录。任何故障停机的一次记录为失败，不替换成成功曲线。
