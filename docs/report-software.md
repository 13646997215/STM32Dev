# 报告软件素材与事实记录

这是软件部分素材，不是已完成的课程实验报告。机械设计、成员分工、六次真实进度、到场情况、实测数据和每人心得由用户按事实补充；不能从代码生成虚构实验。

## 第一章：系统方案

本系统以STM32F401CCU6为单控制器，GY953提供姿态，双电机FG提供转速/里程增量，HC05/CH340提供研发观察链路。结构框图见architecture；引脚与单位见hardware-contract。备用硬件不增加分布式通信复杂度。

轮速内环每轮一个PI；平衡/路径外环生成v/w，经差速共同限幅后成为轮速目标。PC不参与实时闭环。低速采用FG周期法，足够脉冲的20ms窗采用计数法；用实际dt积分，含抗饱和和换向静默。

方案取舍：使用GY953已融合姿态，不再叠加不明融合算法；平衡变化率采用短一阶滤波，不照搬长FIR而增加未测相位延迟；无视觉/测距条件下，里程只作估计，保留能力边界。

## 第三章：验证与计算

轮周理论值 `π×0.067=0.210487m`。若且仅若实测PPR为738，一脉冲理论距离约0.2852mm。这个计算不能证明打滑/受载轮径/PPR正确。

端高差30mm与1.6m板长对应1.074°，GY953标称2°精度说明必须用真实高度对照。连续稳定10s、任务时限、坏帧/粘拆包/回绕/故障锁定已通过软件测试；真实高度、时限、停止距离与40mm定位误差尚未测。

软件验证结果见test-results/verification.json；不要把assertion数量当成独立实验工况数量。GUI演示是合成数据，mission测试是注入状态输入，均不是物理动力学仿真。实测后附原始JSONL/CSV、配置/hash、视频、坐标/单位和误差统计，再写性能结论。
