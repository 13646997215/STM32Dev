# IMU预定安装方向参数（尚未装机）

来源为用户声明的安装约定：GY953 X指车前、Y指车右、Z指车下；前端抬高时原始Pitch增大，水平左转时原始Yaw减小。不是本轮已经完成安装/零偏/磁场干扰标定的证据。

文件：PC/config.imu-mount-provisional.json。适用于当前GUI“参数与标定→加载并逐项发送”，schema为1。

| key | 字段 | 值 | 依据 |
|---|---|---:|---|
| 101 | pitch_axis | 1 | 使用GY953原始Pitch（不是Roll） |
| 30 | pitch_zero_deg | 0 | 临时占位，单位度，装机水平实测后改 |
| 33 | pitch_sign | +1 | 前抬映射为正倾角 |
| 32 | yaw_sign | -1 | 原始左转减小，控制约定左转为正 |
| 31 | board_heading_rad | 0 | 临时参考，单位弧度，最终沿板A→远端时实测后改 |
| 100 | cal_flags | 0 | 所有实际标定有效位保持未确认 |

软件映射为`pitch = raw_pitch - pitch_zero_deg`和`yaw = wrap(-raw_yaw * pi/180 - board_heading_rad)`。该文件仅配置当前控制使用的Euler姿态；没有把所有加速度/角速度/磁场原始数据转成另一套XYZ坐标，不能把原始观测tab中Yaw的负向变化当作转换失败。转换后看界面顶部Pitch/Yaw；原始tab保留GY953原数值。

两个偏置设0不意味着把传感器当前放置姿态归零。当前朝向不是0度时显示非零Yaw正常。装机后水平测量原始Pitch作为key30；车头指向最终板A→远端时，取`wrap(-raw_yaw*pi/180)`作为key31。未有最终板朝向时临时参考需要重新确认。balance_sign为平衡输出反馈方向，与本次姿态符号不同，未经试验不改变。

导入前电机12V断开、ARM0；普通参数修改会清空cal_flags，最后再次写key100=0。GUI每项等ACK，拒绝会停止；全部OK后确认flags仍00。该文件只覆盖表中六项，不改轮径/轮距/PPR/PI等其他值。参数在RAM，控制板复位或断电后丢失，需要重新导入。JSON是输入记录，不是设备读回。

在线改变yaw_sign的相关修复：旧App在两个Euler帧之间改符号可能把新符号raw_yaw与旧continuous_yaw混用，留下角度偏差；新App仅在合法配置成功且yaw_sign实际变化时重新建立航向累计。相同值重写和非法配置不清累计。必须使用本次修复后的固件；不能通过重启后丢失参数来规避该缺陷。

用户下载当前Debug固件并继续运行后，启动GUI连接A端CH340，导入此文件。前端抬高应使顶部Pitch增大，水平左转应使顶部Yaw在避开±180度边界时增大。先前的复位误转问题仍未处理，保持CAL_POWER无效，不进入ARM或运动。当前预设不等同CAL_IMU标定通过。
